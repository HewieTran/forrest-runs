# Appearance presets

Approved direction: Forest trail is the default; users can choose Forest trail, Open road, or Slate (solid color). Curated original artwork surrounds flat opaque content surfaces. The active hero's old corner gradient is removed. These are three complete presets; the earlier exploratory four-swatch picker is superseded by the approved three choices. Workout time-of-day art stays independent.

Acceptance: signed-in users find Appearance in every shared app header; desktop drawer and mobile full-screen sheet offer labeled radio choices with outline/check/text selection state. Preview applies immediately without saving. Cancel, close, outside click, Escape and Back discard the preview. Apply persists to the authenticated account across reload and pages. Saving blocks dismissal; errors retain selection for retry; a stale profile requires explicit reload of the latest profile. Page unload warns during unsaved preview/saving. Header/greeting/cards/empty state use solid surfaces for readability. Reduced-motion is honored. Preview mode and signed-out pages keep their existing presentation.

Storage: append migration0012 adds appearance to training_profiles with forest default and a whitelist check. Existing names/avatar preferences and training rows remain unchanged. Appearance PATCH derives owner from the server session, shares optimistic profile versions, and updates only appearance. Legacy name/color saves preserve appearance. No new service/dependency, image upload or paid provider call. Full-account backupv9 includes appearance; v1–v8 normalization and block-scoped v7 are retained. Use the existing deployment database backup and rollback procedure; tests use disposable databases.

Assets: public/appearance/forest.webp and road.webp are original built-in generated images, with small local thumbnails. Prompts: misty sage forest with pale central/top negative space and pine trees at edges/bottom; muted daylight countryside road with pale sky and meadows at the lower edges. No movie imagery. Full wallpapers total about192KB and thumbnails about12KB. Images are decorative CSS backgrounds, use the same cacheable path across pages, have no animation and retain a solid-color fallback.

Verification: pure validation/default/backup tests plus shared production API scenarios run on Node/SQLite and Worker/D1. Check old profile updates, concurrent versions, cross-account isolation, restart persistence and all training regressions. Record actual browser checks and limitations in the PR. No merge or deployment without the existing release process.
